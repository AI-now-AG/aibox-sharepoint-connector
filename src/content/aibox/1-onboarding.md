# Übersicht

Die aibox besteht aus 3 Hauptbereichen. KI Anwendungen, KI Audio Tools und Einstellungen. Diese Funktionen werden in den Folgen Kapiteln weiter beschrieben.

![image1](/soki-somedia.png)

# KI Anwendungen

Hier können die firmenspezifischen KI Anwendungsfälle ausgeführt werden. Über die Navigation einfach das gewünschte Thema und gewünschten Prompt auswählen und den gewünschten Input erfassen.

Als Input können gewählt werden 

* Text  
* Datei (PDF, TXT, JSON, SVG, JPEG, PNG)

Ausführung des Prompts kann über Pfeil oder Ctrl+Enter erfolgen  
![image2](/soki-somedia.png)

Das Resultat wird im Fenster angezeigt und kann direkt aus dem Output kopiert werden. Falls eine Verbesserung, Präzisierung oder ein weiterer Text verarbeitet werden soll, können weitere Eingaben direkt im Eingabefeld erfasst werden.

![image3](/soki-somedia.png)

**Zu beachten**: Die Resultate werden nicht gespeichert. Sobald ein anderer Prompt oder Anwendungsfall aufgerufen wird, werden alle Daten gelöscht. 

# KI Audio Tools

Dies ist ein optionales Feature und muss separat aufgeschaltet werden.

Hier können Audiofiles (aktuell bis zu 25 MB) hochgeladen und transkribiert werden. Es gibt aktuell 3 verschiedene Anwendungen:

* **Audio zu Text**: Transkribiert das Audio 1:1 in Text. Die Qualität des Outputs hängt dabei auch von den Instruktionen ab. Ist das Resultat nicht gut genug, muss dies der aibox Admin prüfen.  
* **Audio zusammenfassen:** In diesem Fall wird das transkribierte Audiofile direkt zusammengefasst. Die Art der Zusammenfassung hängt dabei auch von den Instruktionen ab. Ist das Resultat nicht gut genug, muss dies der aibox Admin prüfen.  
* **Untertitel erstellen**: Hier können aus der Audiodatei verschiedene Untertitel Formate (.ass, .srt) erstellt werden. Ist das Resultat nicht gut genug, muss dies der aibox Admin prüfen.

# Einstellungen

Diese Funktionen können nur durch einen aibox Admin ausgeführt werden.

## Prompts

In der Prompt-Verwaltung werden alle erstellten Prompts abgebildet. Folgende Aktionen können hier ausgeführt werden:

* Prompt filtern und suchen  
* Neue Prompts erstellen  
* Prompt bearbeiten  
* Prompt duplizieren (kopieren)  
* Reihenfolge der Prompts ändern  
* Prompts löschen

![image4](/soki-somedia.png)

Jeder Prompt besteht aus folgenden Informationen

* Titel  
* Kategorie/Anwendungsfall: Legt fest wo der Prompt angezeigt wird  
* Instruktionen: beinhaltet Informationen, welche immer mit dem Prompt mitgegeben werden. Ist für jeden Prompt separat definiert.  
* Knowledge Base (optional): beinhaltet Informationen, welche immer mit dem Prompt mitgegeben werden. Die Knowledge Bases können individuell zu den Prompts hinzugefügt werden.

![image5](/soki-somedia.png)

Die Prompts können als Admin auch direkt in den KI Anwendungen angepasst werden.

![image6](/soki-somedia.png)

## Knowledge Base

Hier können mehrere Knowledge Bases erfasst werden, welche dann in den Prompts hinzugefügt werden.

## Kategorien

Hier können Kategorien und Anwendungsfälle erfasst und die Reihenfolge angepasst werden. Diese können dann in den Prompts hinzugefügt werden.

![image7](/soki-somedia.png)

## Audio Tools Instruktionen

Dies ist ein optionales Feature und muss separat aufgeschaltet werden.

Hier werden die Instruktionen für die Anwendungsfälle Transkription bereitgestellt. Diese können auch komplett ausgeblendet werden und sind dann für die User nicht sichbar.

![image8](/soki-somedia.png)

## Benutzerverwaltung (ab Januar 2025\)

In dieser Ansicht sind folgende Aktionen möglich:

* Neuen Benutzer erfassen  
* Bestehende Benutzer sperren oder löschen  
* Rolle ändern (Admin oder Benutzer)

Bei Nutzung von Enterprise Login sind einige Funktionen nicht verfügbar.
